# Directions

A **direction** is a complete art direction: a mood sentence, axes, the site types and subjects it fits (and doesn't), neighbours to avoid in the same trio, a full `tokens.css` that implements the token contract (fonts with Hebrew fallbacks in the same stack), essence, signature moves, colour roles, typography, layout, components, backgrounds, motion budget, imagery, RTL notes, Do/Don't, **3 palette drops** (each with a complete override line and measured WCAG contrast) and **knobs**.

There are **33**. Each one has a live specimen page (`studio-design/directions/_specimens/<slug>.html`) and three screenshots: `<slug>.jpg` (1440×900 LTR), `<slug>.rtl.jpg` (1440×900 Hebrew/RTL) and `<slug>.m.jpg` (390×844 mobile). Brands and copy in the specimens are fictional.

RTL montage: [`_montage.rtl.jpg`](../studio-design/directions/_specimens/_montage.rtl.jpg). To browse the specimens interactively, serve the skill folder (`python3 -m http.server -d studio-design`) and open `/directions/_specimens/index.html`.

## Reading the table

- **Axes**: paper band · display style · accent band · radius system · density-variance-motion (0–10 each). See [how-it-works.md](how-it-works.md#the-axes).
- **Fits**: the site types the direction is allowed for (`ecommerce`, `landing`, `company`).
- **Hebrew display**: the Hebrew face the direction ships with and its class, which is used for distance on Hebrew sites. Most directions also list a swap face for when the class collides within a trio.
- *(guarded)*: sits on or next to a current attractor. It's only used when the brief's words or content demand it, and then with the guard block in the file.

## Guarded directions

| Direction | Why it's guarded | Guard |
|---|---|---|
| `broadsheet-duet` | Sits on attractor A4 (broadsheet hairlines, 0 radius) | Only when the brief says newspaper/magazine/journal, or the site has ≥6 real long-form articles; no cream paper, no hairline under every row |
| `media-bento-night` | Dark + one neon accent cluster | Accent never acid green/lime; real media fills ≥60% of the first two viewports; every tile shows real product output |
| `dev-playground` | Source look is near-black + lime (attractor A3) | Warm charcoal canvas, lime banned; every kinetic effect must demonstrate the product's capability |
| `void-stage` | Dark + 3D, next to attractor A7 (dark AI hero + floating 3D) | The 3D content is the client's real work, place or object, never an abstract sphere; poster fallback |

## Quick routing hints

These are starting points; the algorithm still runs.

- **Commerce, product-led**: pantry-label (food/drink DTC), industrial-catalogue, darkroom-object, campaign-commerce, couture-condensed, index-mono-gallery, cold-chrome-luxury, herbarium, cosmic-retrofuture.
- **Professional services / trust** (law, clinics, accounting): architect-calm, swiss-signal-grid, whisper-studio, machined-soft. Add estate-didone for private clinics, forest-bone-heritage for family firms, broadsheet-duet for firms that publish, telemetry-terminal (prose mode) for compliance/cyber.
- **B2B / corporate**: cell-ledger, atmospheric-sky, swiss-signal-grid, telemetry-terminal, film-title-bands, architect-calm.
- **Youth / consumer / events**: inflatable-pop, billboard-type, neo-brutal-exhibit, desktop-y2k, storybook-sketch, organic-colour-block.
- **Agency / studio own site**: the work supplies the colour, so accent-less directions come first. The default for a studio with ≥6 strong projects is work-wall-neutral; then void-stage, film-title-bands, swiss-signal-grid, index-mono-gallery, billboard-type, cell-ledger.
- **Israeli consumer finance, telecom, apps, public services** (Hebrew-first, statement-led): kikar-heavy, with swiss-signal-grid or cell-ledger as the cooler alternative.
- **Tech products**: telemetry-terminal, apparatus-night, whisper-studio, machined-soft, dev-playground, media-bento-night.
- **Strongest in Hebrew**: kikar-heavy (designed Hebrew-first), work-wall-neutral, swiss-signal-grid, architect-calm, telemetry-terminal, index-mono-gallery, storybook-sketch, neo-brutal-exhibit, organic-colour-block, herbarium, forest-bone-heritage. Weakest, because the signature partly depends on Latin-only features: couture-condensed, estate-didone, cold-chrome-luxury, film-title-bands. These have RTL notes.

## Colour rules shared by every direction

- `ink/canvas`, `ink-2/canvas`, `muted/canvas`, `muted/surface`, `ink/surface` and `accent-ink/accent` are all ≥ 4.5:1 (script-checked, oklch → sRGB, WCAG 2).
- Every palette drop ships a complete override of all 10 contract colour tokens, plus its measured contrast.
- When `accent/canvas` < 3, the accent is a fill colour only: never text, never a 1px line on canvas.
- `--fs-base` ≥ 16px for prose (≥ 15px in UI-dense directions); labels ≥ 12px.
- `--img-*` tokens are imagery-only colours (glazes, shader stops) and never touch text or UI.

## Adding a direction

See [CONTRIBUTING.md](../CONTRIBUTING.md#adding-a-direction). Copy an existing direction file as the template, implement the whole token contract, add a row to `_index.md` (both tables) with reciprocal neighbours, build a specimen, shoot it with `_specimens/_shoot.mjs`, and rebuild the montages with `_specimens/_montage.py`.
